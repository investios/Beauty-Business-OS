## Не менялось

## Ограничения
- Формы «длинная» для сообщений не написаны (только основная и короткая RU).
- Тексты ветвей даны на русском; EN/UA — основной путь.
- `approved_claim_registry`, `experiment_assignment`, `message_outcome` не созданы: нет утверждённых фактов и реальных отправок.
- Откат: миграцию 0016 можно не применять — код без таблиц читает данные без ошибок (шлюз вернёт «не утверждено», страница покажет черновики); кнопка «Утвердить» заработает только после применения миграции. Для удаления: `DROP TABLE playbook_approval, conversation_state, message_decision`.
