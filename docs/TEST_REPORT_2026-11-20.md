# Отчёт о тестах (20.11.2026, ветка feat/mila-platform, коммит a0ad9ee)

## Автотесты (vitest)
23 файла, **175 тестов, все прошли** (12,9 с). Проверка типов и `next build` без ошибок.

| Область | Файлы | Что проверяют |
|---|---|---|
| Запись и расписание | booking, schedule, calendar, horizon, tz, timeprefs | свободные окна, буфер, пересечения (триггер БД), часовой пояс Дублина, горизонт записи |
| Политики | policies | значения по умолчанию, проверка границ, версии и история, снимок условий при записи |
| Напоминания и возврат | lifecycle, jobs | вечер перед визитом, 2 дня только при записи за 7+ дней, идемпотентность, повтор после сбоя |
| Клиент | client-model | статусы по циклу, ручной статус не сбрасывается, заметки, жалобы, отзывы |
| ИИ | ai, ai-actions, ai-recognition, typing, owner-assistant | сценарии, права инструментов, узнавание только по проверенной ссылке, передача мастеру, язык |
| Мастер отвечает | master-replies, waitlist | ответ мастера уходит в диалог клиента, лист ожидания с согласием |
| Лояльность | loyalty | целые центы, повторное начисление не удваивается, реферал после визита, самореферал заблокирован, VIP-резерв |
| Доступ | auth, login-throttle, consultant | сессии, ограничение попыток, изоляция ролей мастера и консультанта, только агрегаты |

## Браузерные сценарии (Playwright, чистая база, Chromium)
Пройдены: dashboard, crm, calendar-owner, journey, layout (48 комбинаций страниц и ширин 320/390/768/1280 без горизонтальной прокрутки, проверка доступности axe без нарушений на проверенных страницах).
Примечание: при прогоне подряд на одном сервере calendar-owner и journey один раз упали по таймауту входа (ограничение попыток входа). После перезапуска сервера и чистой базы оба прошли. Это особенность тестового прогона, не дефект продукта; в отчёте не скрываю.
Ранее отдельно проверено в браузере: мастер не открывает /consultant, консультант не открывает /owner, пароль мастера не подходит консультанту.
