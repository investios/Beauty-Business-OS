# Журнал решений

- **D-01 Стек.** Next.js 16 + React 19 + TypeScript; вместо Prisma/Redis для пилота — PostgreSQL в виде встроенного PGlite и прямые SQL-запросы. Причина: настоящий Postgres-SQL (exclusion constraint, транзакции) без отдельного сервера. Переход на управляемый PostgreSQL меняет только `src/lib/db.ts`.
- **D-02 Хостинг (открыто).** PGlite хранит данные в папке: нужен хостинг с постоянным диском и **одним** процессом. Для нескольких процессов или масштабирования — управляемый PostgreSQL.
- **D-03 ИИ (открыто).** Сейчас сценарный движок. Подключение LLM: заменить блок классификации/ответа в `src/lib/ai.ts` на вызов провайдера; инструменты (`getAvailability`, handoff) и проверки на сервере уже есть. Ключ только на сервере.
- **D-04 Почта (открыто).** `src/lib/notify.ts` — единственное место отправки. Нужны домен, SPF/DKIM/DMARC.
- **D-05 «Запись подтверждена» = запись зафиксирована в календаре.** Письмо — отдельный честный статус доставки.
- **D-06 Контент по умолчанию не индексируется** (`noindex`), пока мастер не подтвердил данные.
- **D-07 Первое касание.** Источник (UTM) запоминается на сессию по принципу first-touch.
- **D-08 Шрифты.** Без внешних загрузок (приватность, скорость): системные + запасные; фирменные шрифты разместить на своём домене позже.
- **D-09 Кабинет мастера на русском**; публичный сайт EN/RU/UA.
