# Журнал решений

- **D-01 Стек.** Next.js 16 + React 19 + TypeScript; прямые SQL-запросы через тонкий слой `src/lib/db.ts`. Ноябрь 2026: база переведена с встроенного PostgreSQL (PGlite) на SQLite/Cloudflare D1 по решению Ника выкладывать всё на Cloudflare.
- **D-02 Хостинг.** Cloudflare Workers + D1 (решение Ника). Нужен API-токен Cloudflare для выкладки, см. `docs/DEPLOY_CLOUDFLARE.md`.
- **D-03 ИИ (открыто).** Сейчас сценарный движок. Подключение LLM: заменить блок классификации/ответа в `src/lib/ai.ts` на вызов провайдера; инструменты (`getAvailability`, handoff) и проверки на сервере уже есть. Ключ только на сервере.
- **D-04 Почта (открыто).** `src/lib/notify.ts` — единственное место отправки. Нужны домен, SPF/DKIM/DMARC.
- **D-05 «Запись подтверждена» = запись зафиксирована в календаре.** Письмо — отдельный честный статус доставки.
- **D-06 Контент по умолчанию не индексируется** (`noindex`), пока мастер не подтвердил данные.
- **D-07 Первое касание.** Источник (UTM) запоминается на сессию по принципу first-touch.
- **D-08 Шрифты.** Без внешних загрузок (приватность, скорость): системные + запасные; фирменные шрифты разместить на своём домене позже.
- **D-09 Кабинет мастера на русском**; публичный сайт EN/RU/UA.

## Решения этапов 3–5 (20.11.2026, Master TZ v2.0)

- **D-10 Правила в данных, не в коде.** Лимит отмены, напоминания, цикл возврата, VIP-резерв лежат в `policies` с версиями; запись хранит снимок условий, действовавших при записи (`appointment_terms`). Новые правила не меняют старые записи задним числом.
- **D-11 Цикл возврата 28 дней** — тестовое значение. Статусы: 1/2/3 пропущенных цикла дают «просрочен / в риске / потерян». Ручные «неактивен» и «архив» сохраняются до нового завершённого визита. Мила подтверждает цикл.
- **D-12 Лимит отмены 12 ч, буфер 30 мин** — стартовые значения, меняются в «Настройках».
- **D-13 ИИ работает только через серверные инструменты.** Матрица auto / confirm / master в `ai-tools.ts`. Клиента ИИ узнаёт только по проверенной ссылке управления записью, не по имени, почте или телефону.
- **D-14 VIP и скидки решает мастер.** ИИ принимает срочную просьбу VIP и передаёт мастеру; ничего не обещает сам.
- **D-15 Резерв VIP по умолчанию 0 % (выключен).** Рекомендую включить 10 % с освобождением за 48 ч, когда у Милы будут VIP-клиенты. Включает мастер.
- **D-16 Бонусы в целых центах, не float.** Идемпотентные ключи, метка `is_test=1`. Тестовые размеры: бонус за визит 3 €, реферал 10 €, другу 5 €. Размеры придумал я для проверки механизма, Мила их заменяет.
- **D-17 Реферал засчитывается после реального завершённого визита друга.** Самореферал и один контакт блокируются.
- **D-18 Фоновые задачи с `run_key UNIQUE`.** Повторный запуск не дублирует письма. Три попытки с паузой 10 минут. Вызов `POST /api/v1/cron/tick` закрыт `CRON_SECRET`; без секрета отвечает 404.
- **D-19 Расписание Cloudflare Cron НЕ подключено.** Для этого нужен свой воркер с `scheduled`-обработчиком вместо OpenNext main; это риск для боевого сайта. Пока задачи запускаются кнопкой в «Сегодня» или внешним вызовом tick. Подключение — отдельная задача после согласования.
- **D-20 Консультант.** Отдельный вход, отдельная кука, отдельная соль подписи, пароль из `CONSULTANT_PASSWORD`. Видит только агрегаты без персональных данных. 2FA пока нет.
- **D-21 Голос владельца.** Распознавание и озвучка средствами браузера (работает в Safari на iPhone). Сводка и очередь вопросов только в кабинете.
- **D-22 Миграции аддитивные.** Только `CREATE ... IF NOT EXISTS`, чтобы локальная база применяла все файлы при каждом старте. Номер 0011 пропущен намеренно: лист ожидания использует таблицу из 0005.
- **D-23 Каналы связи.** Порядок: почта, затем Instagram/Messenger, затем WhatsApp. См. `INTEGRATIONS_RESEARCH_2026-11-20.md`.
