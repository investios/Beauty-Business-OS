# CHANGELOG_INTERNAL

## PR1: дашборд владельца (ветка feat/pr1-owner-dashboard)
Зачем: каждая цифра обзора должна вести к записям, из которых она посчитана; поиск и возврат без потери фильтра.

Файлы:
- `src/lib/owner-queries.ts` (новый): единые определения фильтров записей, счётчики и списки, лента действий.
- `src/app/owner/today/page.tsx`: плитки-ссылки с определениями, список ближайших 7 дней, лента последних действий.
- `src/app/owner/appointments/page.tsx`: фильтры (сегодня, 7 дней, новые, ждут, прошедшие, отмены), количество и определение фильтра, постраничный вывод по 25.
- `src/app/owner/appointments/[id]/page.tsx`, `src/app/owner/actions.ts`: параметр `back` (только внутренние адреса `/owner/…`), сохраняется после действий.
- `src/app/owner/search/page.tsx` (новый), `src/components/OwnerShell.tsx`: общий поиск по клиентам, записям и услугам.
- `src/app/owner/clients/[id]/page.tsx`: хронология (визиты, действия по записям, согласия, появление в базе), записи ведут в карточку с возвратом.
- `src/app/globals.css`: плитки-ссылки, поиск, пагинация; устранены переполнения на телефоне 320 px.
- `tests/owner-queries.test.ts`, `tests/e2e/dashboard.cjs` (новые).
- `docs/CURRENT_STATE_MATRIX.md`, `docs/IMPLEMENTATION_PLAN.md`.

Публичный сайт: изменений нет. Миграций нет. Выкладки нет.
Определения метрик (дословно в интерфейсе под каждой цифрой): «Сегодня» (начало сегодня по Дублину), «7 дней» (ближайшие 7 суток), «Новые» (создано за 7 суток), «Ждут подтверждения» (статус «заявка», время не наступило), «Отмены» (статус «отменена», визит не раньше 30 дней назад).

Проверки: typecheck без ошибок; `next build` успешна; vitest 76 тестов; e2e dashboard (49 проверок), crm, schedule, first-screen, calendar, gaps, chat-axe.
Приватность: в скриншотах и тестах только тестовые данные; новых персональных данных не хранится.
