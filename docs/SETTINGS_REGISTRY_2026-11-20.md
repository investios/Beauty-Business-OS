# Реестр настроек мастера

| Настройка | Где | Значение по умолчанию | Статус |
|---|---|---|---|
| Лимит отмены, ч | Настройки | 12 | стартовое |
| Буфер между клиентами, мин | Настройки, кнопка «для всех услуг» | 30 | стартовое |
| Напоминание вечером накануне (19:00 Дублин) | Настройки | вкл | рабочее |
| Напоминание за 2 дня (если запись за 7+ дней) | Настройки | вкл, порог 7 | рабочее |
| Напоминание утром / за час | Настройки | выкл | рабочее |
| «Как прошло» после визита, ч | Настройки | 24 | стартовое |
| Цикл возврата, дней | Настройки | 28 | тестовое |
| Режим «мастер занят» | Настройки | выкл | рабочее |
| Бонус за визит, центы | Настройки | 300 | тестовое |
| Награда за реферал, центы | Настройки | 1000 | тестовое |
| Бонус другу, центы | Настройки | 500 | тестовое |
| Резерв VIP, % | Настройки | 0 (рекомендую 10) | решает мастер |
| Освобождение резерва, ч | Настройки | 48 | стартовое |

Каждое изменение хранится версией с датой; записи сохраняют условия на момент создания.
