# План реализации рекомендаций аудита (Beauty Business OS)

Дата: 2026-11-09. Источник: Beauty_Business_OS_Audit_2026-11-09.md.

## Правила для всех этапов

- Работающие функции (запись, слоты, переносы, отмена, кабинет, ИИ-демо) сохраняем; перед каждой правкой — тест, который сначала падает.
- Факты об услугах только с пометкой статуса: `confirmed_studio` / `confirmed_general` / `needs_owner` / `unknown`. Без утверждения Милой в публичный текст не идут.
- Платные сервисы (почта, LLM, WhatsApp/Instagram, платежи, распределённый лимит за деньги) — только после вашего согласия.
- Перед каждой выкладкой: tsc, unit-тесты, сборка, проверка вёрстки 375/768/1440, axe, реальный прогон записи.

## Этап 0. Выбор оформления (сейчас)

Сделано: три варианта главной `/concepts/a|b|c?lang=ru|en|uk` (A чёрный+шампань, B нюд, C бордо). Один набор компонентов, одинаковые тексты, `data-theme` + токены, шрифты локально (Cormorant Garamond + Manrope, кириллица), 0 ошибок контраста и переполнения.
Результат этапа: клиент выбирает вариант и утверждает/правит заголовок и подзаголовок. Приёмка: письменный выбор A, B или C.

## Этап 1. Основа бренда и честные данные (P0)

1. Модель `brand_config` и таксономия услуг со статусом `pending_approval` (наращивание, коррекция/снятие, консультация по волосам и коже головы, славянские волосы розница/опт).
2. Выбранная тема переносится на реальную главную; старая плюм-палитра убирается.
3. Длительности 45/90/120 помечены как временные; в кабинете поле «подтверждено Милой»; на сайте «длительность уточняется».
4. Цены не публикуем; «индивидуально после консультации».
5. Новая навигация: Главная / Наращивание / Коррекция и снятие / Консультация по волосам / Славянские волосы / Работы / Знания / Записаться; на телефоне приоритет «Записаться» + «Вопрос».
Приёмка: ни одного публичного факта без статуса «утверждено»; тесты на запрещённые формулировки («без вреда», «100% незаметно», «лечение», «гарантия роста»).

## Этап 2. Запись, безопасность и данные (P0)

1. Контакт: разделить e-mail и телефон либо выбор канала с проверкой формата.
2. Доверенный IP: брать только `CF-Connecting-IP`, `x-forwarded-for` не доверять.
3. Лимиты запросов: правила Cloudflare Rate Limiting (платность проверить и согласовать).
4. Кабинет: личные аккаунты и MFA вместо одного пароля; пароль, переданный в чате, сменить перед запуском.
5. Конфиденциальность: юридическая проверка, согласие, маркетинг только по отдельному opt-in, срок хранения, удаление, минимизация данных о здоровье (не хранить диагнозы в свободном тексте, не отправлять в маркетинг).
6. Резервные копии и e-mail подтверждения — только после согласования почтового сервиса.
7. Выгрузки БД не попадают в репозиторий и в архивы для третьих лиц.
Приёмка: нет двойных слотов (тест), контакт валидируется, тест на отсутствие здоровья в маркетинговых выгрузках.

## Этап 3. Фото и результаты (P0/P1)

1. Конвейер реальных фото: поле согласия клиента, alt-текст, единая обрезка, пометка «свет/окрашивание различаются».
2. Публикуются только фото с письменным согласием; заглушки подписаны.
3. Кейсы: до/после, граммовка, длина, оттенок — по разрешению клиента.
Нужно от Милы: фото и согласия.

## Этап 4. Знания и ИИ-консультант (P0)

1. Навык MK Extension Studio v2.0 импортируется как черновик: утверждение Милой обязательно для цен, медицинских и технологических утверждений (ветка `feat/mk-knowledge`).
2. Маршрутизация: технологии, трихология, выпадение, окрашивание, уход, продажи, повторное обслуживание, B2B.
3. Эскалация к врачу: внезапные очаги, зуд/раздражение, беременность, тракционная алопеция и т.д.; ИИ не ставит диагноз и не обещает лечение.
4. 10 сценариев из implementation_plan.md + оценочный набор 50–100 вопросов; свободные ответы включаем только после прохождения.
5. Список вопросов Миле (RU) — отдельный документ.
Приёмка: тесты на красные флаги проходят; ответы с источником и статусом; LLM не подключаем без согласия.

## Этап 5. Жизненный цикл ухода и CRM (P1)

1. Цепочка: консультация → цель → оценка → услуга → уход → проверка → срок коррекции (ставит Мила) → повторное наращивание/снятие.
2. Журнал: тип капсул, партия, граммы, длина, цвет, рекомендации, информированное согласие; доступ по ролям.
3. Напоминания: только предпросмотр вручную, отправка отключена (триггеры БД уже блокируют без одобрения и включённой интеграции); возможность отказаться.
4. Каталог средств по уходу с совместимостью (после ответов Милы).
5. Повторная запись одним действием.

## Этап 6. Сайт для роста (P1)

B2B-заявка на славянские волосы (опт), страница «Технологии: сравнение», структурированная SEO-разметка, мета-описания, sitemap, локальное SEO Дублина, реальные кейсы.

## Этап 7. Позже (P2, не без согласования)

Абонементы, платежи и подписки, автоматические каналы (WhatsApp/Instagram), расширение на несколько мастеров.

## Что нужно от вас / Милы

Выбор темы A/B/C; ответы на 10 вопросов аудита (материал капсул, технологии, критерии отказа, трихология, цены и длительности, происхождение волос, уход, права на фото, календарь/почта/адрес, маржа); решения по платным сервисам.
