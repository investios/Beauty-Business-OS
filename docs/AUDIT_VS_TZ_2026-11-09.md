## 3. Риски и решения по контенту

- Макет содержит утверждения «Более 10 лет», «Сотни довольных клиентов», «решения причин выпадения». Без подтверждения Милы **не публикуем**; в вопросах к Миле.
- Сгенерированное изображение Милы не используем, только реальные фото. Лица клиентов без согласия не публикуем.
- Нет отзывов, до/после, цен, длительностей (как и раньше).
- Статьи — «на утверждении у Милы», `noindex`; медицинских обещаний нет, только общее образование и совет обратиться к врачу.

## 4. План этапов

1. Токены, шапка, подвал, главная → тесты.
2. Страницы: О Миле, Услуги + 4 хаба + консультация, Результаты, Контакты → тесты.
3. Библиотека и статьи → тесты.
4. ИИ + библиотека → юнит-тесты и чат-прогон.
5. SEO и документ семантического ядра.
6. Полная проверка (375/768/1440, RU/EN/UA, axe), сборка, выкладка, живая проверка чата и записи, отчёт.
