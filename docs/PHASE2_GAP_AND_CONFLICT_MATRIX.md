## 3. Сделано иначе, чем описано в ТЗ

1. **LLM уже подключён** (ТЗ предполагает «выяснить»). Сделано на Cloudflare Workers AI без ключей, не через внешнего провайдера. Это ответ на вопрос §4: переиспользуем.
2. **Hold есть в ядре, но не в интерфейсе.** ТЗ просит hold в AI-записи, делать нужно только API+чат, не переписывать ядро.
3. **Сайт без «ваши отзывы/10+ лет»** намеренно, а макет их содержит (см. `AUDIT_VS_TZ_2026-11-09.md` §3).
4. **Нижняя панель на телефоне всегда видна** (решение 10.11 после жалобы на дубль кнопок). Для главной ТЗ-P0 требует иной баланс → предлагается IntersectionObserver только на главной.
5. **Чат печатается по словам** по прямой просьбе владельца 09.11 (не «блоками»); учесть при любой переработке диалога.

## 7. Конфликты, по которым нужно решение владельца

**К-1. Нижняя панель vs кнопки hero на главной (мобильная).** Варианты: (А) панель скрыта на главной, пока видны кнопки hero, потом появляется (рекомендую); (Б) панель всегда, а в hero только одна кнопка; (В) вернуть прежнюю панель «после прокрутки».
**К-2. AI-путь записи vs календарь.** ТЗ: AI основной путь, календарь резерв. Сейчас на главной главная кнопка ведёт на календарь. Варианты: (А) главная кнопка открывает чат с готовой репликой «хочу записаться», вторая ссылка «выбрать в календаре» (рекомендую после P1); (Б) оставить календарь основным до завершения P1; (В) две равные кнопки.
**К-3. Идентификация при переносе/отмене в чате без почты.** Варианты: (А) только по личной ссылке из подтверждения (сегодняшний уровень безопасности); (Б) по одноразовому коду на почту/телефон — нужна подключённая отправка (P3 зависимость); (В) передача мастеру.
**К-4. Два источника знаний AI.** Варианты: (А) перенести `ai-knowledge.ts` в таблицы знаний как черновики на утверждение (рекомендую); (Б) оставить статичный текст до ответов Милы; (В) отключить LLM для тем без утверждённых карточек.
**К-5. Ветка `feat/mk-knowledge` и нумерация миграций.** Варианты: (А) влить после ревью, перенумеровав ближайшие миграции; (Б) вырезать только `claims` и 0002 сейчас, 0003 позже (рекомендую); (В) не вливать, держать как справочник.
