# ГОТОВЫЙ ПРОМПТ ДЛЯ CLAUDE CODE

Прочитай вначале `00_START_HERE/README_FIRST.md`, затем **все** Markdown-документы по порядку из README. Сохрани следующие продуктовые решения без изменений: (а) основной продукт — для конкретного beauty-мастера в Ирландии, не воронка консультанта; (б) индивидуальный premium mobile-first сайт, но переиспользуемая архитектура; (в) прямое бронирование и добровольный AI-консультант; (г) утверждённая мастером экспертная база + продажи + инструменты бронирования; (д) единая CRM/booking база, мультиарендность; (е) EN/RU/UA; (ж) официальный Instagram-канал только после реальной проверки permissions, без личных сообщений за простой лайк.

Начни с изучения `07_DEMO/index.html` как *clickable UI reference*, не считать его production-кодом. Затем создай в репозитории план внедрения по P0 (основа, сайт, запись, CRM, AI, уведомления), P1 (соцканалы/маркетинг/лояльность), P2 (расширение). Зафиксируй все placeholder данные в `docs/OPEN_QUESTIONS.md`; не изобретай бренд, реальные фото, цены, медицинскую технологию и квалификации.

Собери frontend на предложенном TypeScript/React/Next стеке с responsive design согласно `03_DESIGN_UX/DESIGN_SYSTEM_AND_UX_BRIEF.md`. Реализуй booking backend с PostgreSQL/транзакциями, типизированными endpoint, защитой от двойной записи и Europe/Dublin DST. AI-оркестрацию делай через adapter, approved-KB и function calls; все LLM-предположения отделяй от фактических действий сервера. Для любой недоступной внешней интеграции делай явный provider stub, не показывай пользователю fake «подключено».

Запусти/протестируй мобильный client journey, чат, запись, owner dashboard; тесты concurrency, DST, i18n, тенантной изоляции, ошибочной цены, human handoff. Верни список файлов, тестовые результаты и конкретные открытые блокеры с указанием, какие сведения нужны от мастера для замены демо на production.

При возникновении вопросов сначала ищи ответы в `01_CONTEXT_AND_RESEARCH/DECISION_HISTORY_2026-11-06_TO_11-09.md`: эта история содержит уточнения пользователя и отменённые направления, которые не следует заново предлагать.
