# BRIEF ДЛЯ CLAUDE CODE · 9 ноября 2026

## Одной фразой
Построить брендируемую beauty-платформу для индивидуального мастера: красивый мобильный сайт + утверждённый экспертный AI-консультант + онлайн-запись + CRM + автоматические коммуникации + измеримый маркетинг + простой кабинет мастера. Это не лендинг с внешней кнопкой и не «обычный чат-бот».

## Текущий заказ
Есть реальный мастер в Ирландии, основной контакт с клиентами идёт из Instagram; клиенты говорят на английском, украинском, русском. Услуга описана как наращивание волос и отдельная авторская технология, связанная с густотой/ростом волос. Её точную технологию и профессиональные утверждения мастер передаст позднее. Нельзя автоматически подставлять вымышленные цены, сертификаты, результаты, отзывы, реальные фотографии, медицинские описания и гарантии.

## Показать на ближайшей встрече
1. Красивую mobile-first главную с портфолио (временно явно маркированное demo), услугами, доверием, 2 CTA: «Записаться» / «Задать вопрос».
2. Два самостоятельных пути: быстрый выбор тестового слота и консультация → слот.
3. Мультиязычный демонстрационный диалог RU/EN/UA, корректный ответ на ценовой вопрос и передачу сложных вопросов человеку.
4. Подтверждённую **внутри демо** запись в календаре и её карточку клиента в кабинете мастера.
5. Пояснение маркетингового пути Instagram/партнёр/сайт → AI/бронь → CRM → повтор/реферал.

## Основная архитектура
- Public web/PWA + owner mobile PWA + ограниченный operator console.
- Services/Staff/Resources/Bookings с атомарным бронированием и проверкой пересечений.
- Clients/Conversations/Consents/Knowledge/Marketing Sources/Events/Referral/Waitlist.
- AI с утверждёнными карточками знаний и versioning; вызов функций только через backend с проверками.
- EN/UA/RU язык контента и AI независимо от языка мастера.
- Multi-tenant модель с первого дня, один мастер в пилоте.
- Сначала локальный тестовый прототип, затем production-бекенд и официальные интеграции.

## Вне текущего объёма
Собственная воронка привлечения мастеров, продажи консалтинга, расширенный Business OS (финансы/стратегия/найм), TikTok без подтверждённого API, реальный голосовой обзвон, сложная loyalty economy. Подготовить интеграционные швы, но не строить сейчас.

## Приоритеты
**P0:** сайт, логика записи, CRM, обучение AI на утверждённых данных, ручной переход к мастеру, owner dashboard, source tracking, типовые транзакционные уведомления, базовая безопасность.
**P1:** Instagram official integration, waitlist, возврат, рекомендации, partner QR, rebooking, дневной дайджест, расширение на команду.
**P2:** TikTok/voice/campaign studio/Business OS.

## Продуктовые инварианты
- Клиент никогда не должен устанавливать приложение ради записи.
- Обычная запись работает, даже если AI выключен.
- AI не подтверждает запись до успешного ответа booking API.
- Доступные слоты только из реального состояния календаря.
- Система не пишет незнакомым людям просто за лайк и не нарушает messenger policies.
- AI не придумывает цены/даты/диагнозы и не отправляет чувствительные данные партнёрам.
- При отсутствии реальной интеграции UI должен говорить «Демо» / «Заявка, ожидает подтверждения», а не притворяться реальным бронированием.
