# ДИЗАЙН-ТЗ: САЙТ BEAUTY-МАСТЕРА · MOBILE-FIRST

## Задача, аудитория, позиционирование
Продавать результат, мастерство и доверие через визуальную историю, затем облегчать осознанный выбор и запись. Главная аудитория пилота — клиенты услуг волос, говорящие EN/RU/UA, часто приходящие из Instagram. Не использовать гендерные стереотипы о «девочках». Подходить к выбору через портфолио, реальные отзывы, ясность стоимости, ощущение безопасности, персональное отношение и удобную запись. Для множества салонов используем переиспользуемые блоки, но **разные выразительные бренды**.

## Арт-дирекшн A (рекомендуемый пилоту): editorial-luxe, тёплая уверенность
Ассоциации: журнал о красоте, реальное живое фото, уверенная экспертиза, приглушённая дорогая палитра, тонкие линии и много воздуха. Без избыточных блёсток, розового глянца, космических градиентов и шаблонной «женственности». Внимание к волосам как к результату искусства.

### Цветовые токены — точные отправные значения
- `--ink: #282226` — основной текст и логотип.
- `--plum: #4A2D45` — заголовки/рамки/фирменный акцент.
- `--plum-strong: #351D31` — CTA hover/active и контрастная подложка.
- `--rose-dust: #B68B9E` — дополнительный мягкий акцент.
- `--champagne: #D9B99B` — мелкие premium-детали, не основной текст.
- `--ivory: #FAF7F4` — основная подложка.
- `--paper: #FFFFFF` — карточки и формы.
- `--stone: #E8DEDA` — границы, разделители.
- `--muted: #6D6266` — вторичный текст.
- `--success: #276B51`; `--danger: #A13F4C` — системные статусы (не декоративные).

**Кнопка primary**: `#4A2D45` с белым `#FFFFFF` (проверять AA >=4.5:1 на фактических сочетаниях). Secondary: прозрачная светлая с темной обводкой. Дизайн должен работать без градиента — без выцветших низкоконтрастных надписей на фото.

### Шрифты и размеры
Отображение: `Cormorant Garamond` / fallback Georgia для editorial-title (только латиница/кириллица при наличии поддержки; проверить всех трёх языков). Интерфейс: `Manrope`/`Inter` + system. Mobile H1 42–52px/1.05, desktop 68–82px; H2 30–42; H3 22–26; body 16–18/1.5; mini labels 12–14/1.4. Не уменьшать интерфейс до 11px ради красоты. Спокойный ритм текста. Для темной фотографии — сильный градиент-оверлей и проверенный контраст.

### Layout
Mobile container: padding 20–24px, max width 560 для содержимого; Desktop content max 1180–1280px с сеткой 12 колонок. Мобильный sticky CTA «Записаться» после прокрутки hero, но не закрывает контент/формы. Карточки radius 16–24px; input radius 12px; actions min 44×44px; focus-visible prominent. Полезные microanimations <200 ms, `prefers-reduced-motion` respected. Не делать «прыгающие» диалоги или агрессивные попапы.

## Другие бренд-направления в том же коде
**Warm Personal Expert:** `#F5EFE7` + `#49352D` + `#B77C60`, более живые закулисные кадры и лицо мастера, hand-written signature accent только в логотипе.
**Clean Professional:** `#F7F8F7` + `#27383B` + `#79A3A3`, модульные карточки протоколов, спокойный экспертный тон, особенности подготовки/ограничений. Выбрать бренд-тему на основании референсов мастера, не произвольно.

## Первый экран (0–5 секунд)
1. Логотип/название салона + EN/RU/UA language menu, компактная навигация.
2. Основная реальная фотография качественной работы мастера с согласием; если фото ещё нет — **явная demo заглушка**.
3. Одно конкретное ценностное предложение, например в демо «Индивидуальная работа с красотой ваших волос». Без гарантий роста/восстановления неустановленной технологии.
4. Главный CTA «Выбрать время», второй «Задать вопрос AI-консультанту».
5. Короткий блок доверия: специализация, понятное описание подхода, местоположение только если подтверждено.

## Карта страниц и секции
**Home:** hero → три явные категории услуг / проблема-решение → портфолио с контекстом → как проходит консультация → мастер/команда → реальные отзывы → FAQ → Booking & address. Стандартный CTA повторяется после сильных блоков.
**Service detail:** название → понятная суть → кому подходит → этапы/длительность → диапазон стоимости или правила оценки → уход/ограничения → подтверждённые фото → CTA/consult.
**Master:** лицо/голос → квалификации только фактические → специализация → кейсы → availability.
**Portfolio:** реальные фото/видео по категории/мастеру, без ложного before-after и автоматического retouching.
**Booking:** выбор услуги → слот → контакт и только необходимые вопросы → подтверждение. Guest path. После AI консультации выбранная услуга/контакт подставляются только с разрешением.
**Consultation:** добровольный AI виджет/страница, честная маркировка, поддержка EN/RU/UA; возможность handoff мастеру.
**Loyalty:** лёгкий referral/share flow, без обязательного client app, без бонуса за Google review.
**Policy:** privacy, cookies, cancel/reschedule, marketing preferences.

## Психология выбора / UX гипотезы
- От Instagram клиент уже увидел фото — не заставлять читать повторно длинную историю, дать прямые service deep-links.
- Цель «узнать больше» и «сразу записаться» равноправны; AI не навязывается.
- Снижение неопределённости: цена или метод расчёта, длительность, подготовка, условия переносов, кто оказывает процедуру.
- Сомнение → полезный объясняющий материал/кейс → консультация → реальный слот. Без манипулятивного дефицита.
- Social proof только реальный, подтверждённый, с разрешением.
- Для разных сегментов тестировать CTA copy, контраст, блок цены и расположение кейсов; не выдавать гипотезы за доказанные закономерности.

## Mobile UI экраны обязательные к макету и тесту
`Home / Service / Portfolio / AI chat / Availability / Booking form / Booking confirmation / My booking link / Owner Today / Owner Client / Owner AI exceptions / Owner Marketing`.
Проверки размеров: 320, 360, 375, 390, 430, 768, 1024, 1440px. Safe-area iPhone, клавиатура при chat/booking, touch targets, sticky bar collision, dynamic text RU vs EN vs UA.

## Performance и SEO
LCP <2.5s, INP <200ms, CLS <0.1 как ориентиры; responsive AVIF/WebP, lazyload below-the-fold, limit video autoplay, WCAG AA, accessible names/form errors, headings semantically consistent, hreflang EN/RU/UA, structured data только по подтверждённому business profile, sitemap/canonical and OpenGraph per service.

## Функциональная приёмка дизайна
Красота не может скрывать запись: после просмотра 1–2 экранов понятно, как записаться. Уменьшение трения: не более необходимых шагов в booking, любой CTA поддерживает глубокую ссылку на услугу/слот. Смысловая нагрузка фотографий выше декоративных абстракций. Мобильные формы не обрезаются при открытой клавиатуре, не ломаются на 320px, RU/UA кнопки не наезжают.

## Контент: строго подтверждать у мастера
Профессиональные фото и разрешения, настоящий прайс или price-from rules, адрес/часы, авторская технология и её допустимые обещания, реальные отзывы, квалификации, политика отмен/предоплаты, реальные FAQ. До получения — editable CMS placeholders. AI-арт — только как *демо-концепт*, не как портфолио выполненной работы.
