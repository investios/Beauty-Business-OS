## 4. Скрытые бизнес-правила и ранее принятые решения (сохранить)

1. Запись «подтверждена» = зафиксирована в календаре; письмо отдельный честный статус (D-05).
2. Мин. срок до записи 2 часа, буфер 15 мин, часы Вт–Сб 10:00–18:00 по Дублину (временные, нужны ответы Милы).
3. Цены не публикуются и не называются, пока `price_mode = unconfirmed`; длительности временные.
4. ИИ всегда представляется ИИ; медицинские признаки, просьба человека, неизвестное → передача мастеру; диагнозов и обещаний результата нет.
5. Автоисходящих сообщений нет без одобрения и включённой интеграции (триггеры БД).
6. Контент по умолчанию `noindex`; статьи «на утверждении у Милы»; индексация только флагом `SITE_INDEXABLE=1` после решения владельца (D-06).
7. Источник заявки — первое касание на сессию (D-07).
8. Без выдуманных фактов: «10+ лет», «сотни клиентов», «решения причин выпадения», отзывы, до/после, цены не показываем, пока Мила не подтвердит (`QUESTIONS_FOR_MILA.md`).
9. Лица клиентов без письменного согласия не публикуем; сгенерированное фото Милы не используется.
10. Кабинет мастера на русском (D-09); публичный сайт RU/EN/UA.
11. Заголовки на сайте без точки в конце.
12. Платное (почта, LLM с оплатой, WhatsApp/Instagram, платежи) — только после согласия владельца.
13. Секреты не в репозитории; токен Cloudflare из чата не хранится и не используется (автодеплой через Git).
14. Выкладка только после полной проверки; после каждой правки перепроверка вёрстки на «кривизну».
