# Готовность MVP (20.11.2026)

## Работает на боевом сайте после деплоя
Запись через сайт и чат, единый движок свободных окон, политики с историей, напоминания (в режиме пробной отправки), статусы клиентов, заметки, жалобы, отзывы, ответ мастера в чат, лист ожидания, сводка на завтра, бонусы и VIP как механизм, кабинет консультанта.

## Чтобы это заработало в боевой базе (делает Николай)
1. Применить в консоли D1 миграции **0012_jobs, 0013_loyalty, 0014_consultant** короткими блоками (SQL в `migrations/`). 0009 и 0010 применены. Статус 0006 не подтверждён: проверить страницу «Сообщения» на кнопку симуляции.
2. В настройках Cloudflare добавить переменные `CONSULTANT_PASSWORD` и, если нужен внешний запуск задач, `CRON_SECRET`. Значения не писать в чат.
Без миграций новые разделы показывают «не готово» и не ломают остальной сайт.

## Не готово и честно помечено
| Что | Статус |
|---|---|
| Реальная отправка писем | режим пробной отправки; нужны домен и почтовый сервис |
| WhatsApp / Instagram / Messenger | не подключены, исследование готово |
| Запуск задач по расписанию | не подключён (D-19); есть кнопка и защищённый вызов |
| Суммы бонусов, цикл 28 дней, цены, тексты | тестовые; ждём 7 анкет Милы |
| 2FA для мастера и консультанта | нет |
| Дизайн | три направления показаны, выбор за владельцем |
| Реальные фото, отзывы, цены | нет, ничего не выдумано |

## Вывод
Ядро (запись, правила, клиент, ИИ-передача, возврат, лояльность) готово к показу Миле. К реальным клиентам: применить миграции, выбрать почту, получить от Милы цены и тексты, провести тест на iPhone.
